# Banked

> Banked is a global account-to-account (A2A) payments network built on open banking that enables real-time pay-by-bank payments for consumers, businesses, and banks. Products include hosted Checkout, Payment Links & QR codes, Payouts, Refunds, Reporting, loyalty (Incentivize), and fraud protection. Authentication is OAuth 2.0 client credentials against api.banked.com; an official hosted MCP server exposes payment tools to agents.

This llms.txt was generated by the API Evangelist enrichment pipeline from the Banked developer surface (no provider-published llms.txt was found).

## APIs
- [Banked Payments API reference](https://developer.banked.com/reference): Payment sessions (checkout), payouts, refunds, and webhooks. Base URL https://api.banked.com.
- [Partner API](https://developer.banked.com/reference): Onboard businesses on behalf of platforms — POST /partner/v1/businesses.

## Authentication
- OAuth 2.0 client credentials; exchange client_id/client_secret (scope = business application ID) for a bearer token at https://api.banked.com/oauth/token.

## Core operations
- Create payment session: POST https://api.banked.com/v2/payment_sessions
- Retrieve payment session: GET https://api.banked.com/v2/payment_sessions/{id}
- Create business (Partner API): POST https://api.banked.com/partner/v1/businesses
- Manage webhooks: GET/POST/PATCH https://api.banked.com/v2/webhooks

## Agents / MCP
- [Banked MCP server](https://mcp.banked.com): OAuth 2.0; tools payments.create, payments.search, payments.refund.
- [example-agents](https://github.com/banked/example-agents): reference project for connecting to the Banked MCP.
